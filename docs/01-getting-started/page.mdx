# Development Guide

`dev-toolkit` houses general-purpose Node.js development packages and demo applications.

Reusable GitHub Actions workflows are provided by [moyarich/reusable-workflows](https://github.com/moyarich/reusable-workflows); workspace release and publishing CLIs are provided by [moyarich/workspace-tools](https://github.com/moyarich/workspace-tools).

## Repository layout

```text
dev-toolkit/
├── .github/workflows/   # this repository's CI callers
├── apps/                # example and playground applications
├── docs/                # development documentation
├── packages/            # independent developer packages
├── package.json
└── README.md
```

## Development

Install the locked dependencies at the root:

```sh
npm ci
npm test
npm run lint
npm run typecheck
```

## Adding a package

Create a package under `packages/` with its own `package.json`. Root npm workspaces include `packages/*`. Keep package-specific usage and examples alongside each package.

## Reusable CI example

```yaml
jobs:
  checks:
    uses: moyarich/reusable-workflows/.github/workflows/reusable_node-ci.yml@v0
    with:
      package-directory: packages/my-package
      node-version: "24"
```

Use [workflow examples](https://github.com/moyarich/reusable-workflows/tree/main/examples) for other supported callers. The `@v0` major tag is intended for stable consumers; use a fixed commit SHA when an immutable workflow revision is required.

## Versioning

Version each package according to its published contract. Versioning and publishing tools live in `moyarich/workspace-tools`; public reusable workflow versioning is owned by `moyarich/reusable-workflows`.

Build tooling such as `@moyarich/vite-plugin-package-bin` stays in dev-toolkit and is configured by packages that need it.
