# Development Guide

`dev-toolkit` is the monorepo for reusable Node.js packages, CLIs, and developer tooling used across Moya projects.

Reusable GitHub Actions workflows are maintained separately in [`moyarich/actions`](https://github.com/moyarich/actions). This repository keeps the implementation packages those workflows consume.

## Repository layout

```text
dev-toolkit/
├── .github/
│   └── workflows/   # repository-local callers and CI
├── docs/
├── packages/
├── package.json
└── README.md
```

## Development

Install workspace dependencies from the repository root:

```sh
npm install
```

Run package tests:

```sh
npm test
```

Run available lint and typecheck scripts:

```sh
npm run lint
npm run typecheck
```

## Adding a package

Create a directory under `packages/` with its own `package.json`. The root npm workspace automatically includes `packages/*`.

A package should be split out when it has an independent responsibility or lifecycle. Closely related commands should remain together until maintaining them separately provides a concrete benefit.

## Versioning

Packages use semantic versioning. Public GitHub workflow versioning is owned by `moyarich/actions`.

## Shared automation packages

`@moyarich/workspace-tools` moved to [`moyarich/actions`](https://github.com/moyarich/actions/tree/main/packages/workspace-tools) because it is the executable implementation used by the reusable workflow platform.

General build tooling such as `@moyarich/vite-plugin-package-bin` remains in `dev-toolkit`. Packages that use it declare it in their own build dependencies; reusable workflows do not depend on or invoke the plugin directly.
