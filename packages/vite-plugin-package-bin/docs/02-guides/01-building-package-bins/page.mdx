# Building package bins

`packageBinBuild` discovers files matching `include` and runs a separate Vite library build for each entry. This keeps every generated executable standalone instead of creating shared runtime chunks.

The plugin:

- validates discovered commands against `package.json#bin`
- removes the output directory before building
- emits each command as an ES module with a Node shebang
- externalizes Node built-ins
- uses `inlineDynamicImports` so each command remains self-contained
- removes its synthetic outer Vite entry from the emitted bundle

## Example with options

```ts
packageBinBuild({
  include: "src/cli/*.ts",
  outDir: "bin",
  target: "node24",
  sourcemap: true,
  minify: false,
  external: ["commander"],
});
```

Additional external dependencies can be strings or regular expressions.

```ts
packageBinBuild({
  include: "src/cli/*.ts",
  external: [/^@inquirer\//, "chalk", "commander"],
});
```
