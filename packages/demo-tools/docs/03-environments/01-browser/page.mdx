# Browser demos

Browser helpers expose Playwright primitives rather than wrapping them in a hidden lifecycle.

```js
import { chromium } from "playwright-core";
import { launchBrowserDemo } from "@moyarich/demo-tools/browser";

const { browser, page } = await launchBrowserDemo({
  chromium,
  url: "http://127.0.0.1:5173",
});

try {
  await page.getByRole("button", { name: "Inspect" }).click();
} finally {
  await browser.close();
}
```

## Browser extensions

Chromium extensions require a persistent context. The helper returns the actual context, service worker, extension ID, and an explicit popup opener.

```js
import { chromium } from "playwright-core";
import { launchBrowserExtension } from "@moyarich/demo-tools/browser";

const extension = await launchBrowserExtension({
  chromium,
  extensionPath: "./dist",
});

try {
  const popup = await extension.openPopup("popup.html");
  await popup.getByRole("button", { name: "Enable" }).click();
} finally {
  await extension.context.close();
}
```
