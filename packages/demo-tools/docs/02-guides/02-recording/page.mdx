# Recording and media

Capture helpers intentionally expose each stage.

```js
import {
  createFrameRecorder,
  encodeGif,
  encodeWebm,
  prepareRecordingArtifacts,
} from "@moyarich/demo-tools/capture";

const paths = await prepareRecordingArtifacts({
  artifactsDirectory,
  name: "basic-colors",
});

const recorder = createFrameRecorder({
  page,
  framesDirectory: paths.framesDirectory,
  frameRate: 10,
});

await recorder.start();

// Perform the visible demo actions.

await recorder.stop();

await encodeWebm({
  framesDirectory: paths.framesDirectory,
  output: paths.webmPath,
  frameRate: 10,
});

await encodeGif({
  input: paths.webmPath,
  output: paths.gifPath,
});
```

This explicit sequence is intentional: a reader can see exactly when recording begins and ends and which encoding steps occur.

## Screenshots

Use `captureScreenshot()` with either a page or locator. The helper creates the destination directory and returns the concrete output path.

## ffmpeg

WebM and GIF encoding require ffmpeg. `ensureFfmpeg()` can be called independently, and encoding functions also verify it before invoking the encoder.

The CLI can encode an existing recording:

```sh
demo gif demo/artifacts/basic-colors/basic-colors.webm
```
