# CLI and discovery

The `demo` executable uses Commander.

```sh
demo
demo list
demo list --json
demo run
demo run basic-colors vscode-editor
demo select
demo interactive
```

In an interactive terminal, bare `demo` opens the fzf strategy selector. In a non-TTY environment, bare `demo` runs discovered strategies deterministically.

Global options:

```sh
demo --strategies demo/strategies list
demo --artifacts demo/artifacts run basic-colors
```

## fzf

The selector supports multiple strategies. Tab toggles a selection, Ctrl+A selects all, Ctrl+D deselects all, Enter runs the selection, and Escape cancels.

The CLI is the execution boundary: it discovers, validates, selects, and runs strategies.
