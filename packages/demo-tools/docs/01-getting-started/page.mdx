# Getting started

Install `@moyarich/demo-tools` and create a strategy beneath `demo/strategies`.

```text
demo/
└── strategies/
    └── overview/
        └── index.ts
```

```ts
import { executableDemoStrategy } from "@moyarich/demo-tools";
import type { DemoStrategy } from "@moyarich/demo-tools";

const strategy = {
  name: "overview",
  description: "Show the primary workflow.",

  async run({ artifactsDirectory }) {
    // Launch the environment explicitly, perform the demo, and write
    // screenshots or recordings to artifactsDirectory.
  },
} satisfies DemoStrategy;

export default executableDemoStrategy(strategy, import.meta.url);
```

`satisfies DemoStrategy` checks the strategy at compile time while preserving
the object's inferred type. demo-tools validates dynamically loaded strategies
again at the runtime boundary.

Run the compiled strategy directly:

```sh
node demo/strategies/overview/index.js
```

Or use the installed CLI:

```sh
demo list
demo run overview
```

Continue with [Strategies](../02-guides/01-strategies/page.mdx) to understand the ownership model.
