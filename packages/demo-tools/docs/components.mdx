# Demo components

Reusable presentation components include captions, cursor overlays, and a magnifier. The strategy controls when and where presentation appears.

## Captions

Caption content and placement belong to the strategy:

```js
await showDemoCaption({
  page,
  caption: {
    title: "Open the color picker",
    description: "Select the CSS color to inspect it.",
    position: "bottom-right",
  },
});
```

The component owns rendering and positioning mechanics. The strategy owns the requested position, content, timing, and removal.

That boundary also permits strategies to use more precise positioning or anchoring when supported by the component rather than forcing every demo into one global location.

## VS Code and Trusted Types

Normal browser pages can load components using the standard component importer. VS Code pages may reject data-URL dynamic imports because of Trusted Types.

`evaluateComponentViaCDP()` provides the lower-level CDP evaluation mechanism. The caller supplies the source transformation explicitly so component behavior remains visible rather than being hidden by a generic installer.
