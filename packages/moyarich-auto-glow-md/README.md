# @moyarich/auto-glow-md

Automatically render Markdown-looking terminal output with Glow from commands run in an interactive Oh My Zsh shell.

## Package layout

    packages/moyarich-auto-glow-md/
    ├── bin/                         # generated by npm run build
    ├── docs/
    │   └── architecture.md
    ├── plugin/
    │   └── moyarich-auto-glow-md.plugin.zsh
    ├── src/
    │   ├── cli/
    │   │   └── moyarich-auto-glow-md.ts
    │   ├── markdown.ts
    │   └── pty-runner.ts
    ├── test/
    │   └── markdown-terminal-coverage/
    ├── package.json
    ├── tsconfig.json
    └── vite.config.ts

## Build

    npm run build --workspace @moyarich/auto-glow-md

The TypeScript CLI source is compiled to:

    bin/moyarich-auto-glow-md.mjs

## Tests

    npm test --workspace @moyarich/auto-glow-md

Terminal/Markdown coverage lives under:

    test/markdown-terminal-coverage

## Oh My Zsh development setup

Build the package, ensure Glow is installed, then source the plugin:

    source /private/var/www/+ai-apps/dev-toolkit/packages/moyarich-auto-glow-md/plugin/moyarich-auto-glow-md.plugin.zsh

The generated package bin must be on PATH. In the workspace you can use:

    npm link --workspace @moyarich/auto-glow-md

## Example

A program can print a Markdown heading or table normally. The ZLE wrapper sends the command through the PTY runner, which preserves TTY behavior and only routes Markdown-looking output through Glow.

See docs/architecture.md for implementation details.
