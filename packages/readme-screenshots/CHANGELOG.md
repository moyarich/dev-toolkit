# Changelog

## 0.1.0

### Added

- Playwright-based CLI for generating repeatable README and documentation screenshots.
- Configuration for target URL, output directory, viewport, screenshot names, selectors, scrolling, and capture delays.
- Sensible defaults for local Vite-style development servers and documentation screenshot output.
- Package-local getting-started, configuration, and CLI documentation.

### Changed

- Build the CLI into `dist/bin` and publish the built `dist/` output.
