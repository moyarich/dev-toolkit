# CLI reference

## run-extension-dev

```sh
run-extension-dev [directory] [options]
```

| Option                     | Purpose                                         |
| -------------------------- | ----------------------------------------------- |
| `--code-command <command>` | Select the VS Code executable.                  |
| `--debug-port <port>`      | Set the extension debugger port.                |
| `--no-compile`             | Skip compilation.                               |
| `--no-open-devtools`       | Do not open developer tools.                    |
| `--no-new-window`          | Reuse an existing VS Code window when possible. |
| `--no-fzf`                 | Disable automatic fuzzy selection.              |
