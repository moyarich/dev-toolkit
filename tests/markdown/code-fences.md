# Code fences

## JavaScript

```js
const message = "hello";
console.log(message);
```

## TypeScript

```ts
type User = {
  id: number;
  name: string;
};

const user: User = { id: 1, name: "Moya" };
console.log(user);
```

## Python

```python
def greet(name: str) -> str:
    return f"Hello, {name}"

print(greet("Moya"))
```

## Go

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Moya")
}
```

## Shell

```sh
printf '%s\n' "hello from shell"
```
