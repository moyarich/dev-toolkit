# Demo Tools Playground

Vite + React workspace for developing and exercising `@moyarich/demo-tools`.

```sh
npm run dev --workspace @moyarich/demo-tools-playground
npm run build --workspace @moyarich/demo-tools-playground
npm run demo:list
node demo/strategies/hello/index.mjs
```

The UI lives in `apps/playground/src/`. Repository-level demo automation lives in `demo/strategies/`, with tests under `tests/`.
